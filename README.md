# sts_combat_rl

Research toward a learned Slay the Spire combat agent.

The simulator is pinned as the [`sts_lightspeed`](https://github.com/gamerpuppy/sts_lightspeed)
Git submodule. This repository owns the agent design and experiments without
copying or forking the simulator.

```bash
git clone --recurse-submodules <this-repository>
cd sts_combat_rl
```

No state representation, action representation, learning algorithm, or neural
network stack has been selected yet.
